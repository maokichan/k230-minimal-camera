# src/ —— CanMV 应用代码（agent 子树入口）

本目录放跑在庐山派 K230-CanMV 固件上的 CanMV（MicroPython）代码。极简相机 = 摄像头取图 → JPEG 编码 → 存 TF 卡；先跑通，再谈扩展（屏幕预览、AI 检测）。

## 硬件与 API 事实

- 平台事实（固件烧录、Sensor/Image/Display/VENC API、文件系统挂载点）**唯一归属 [../docs/research/INDEX.md](../docs/research/INDEX.md)** 及其指向的调研文档；发现代码与调研不符，先改调研文档再改代码。
- 板子：庐山派 K230-CanMV（1GB 内存版）、GC2093 摄像头；固件为立创 CanMV 版（与嘉楠官方 canmv_k230 的差异记录在调研文档）。

## 代码规则

- 写法对齐官方例程口径（庐山派 Wiki 例程与 canmv_k230 示例），不自创 API。
- MicroPython 环境零第三方依赖：只用固件内置模块；需要新模块 = 先查调研文档确认存在，查不到就停。
- 主程序单文件起步（main.py），拆分等到行数或职责确实撑不住——极简是需求。
- 常量（引脚、路径、分辨率）集中在文件头部，不散落魔法值。
- 脚本在板端运行：禁止在本机 pip 安装任何东西来替代板端事实。
