# docs/ —— 项目级文档（agent 子树入口）

本目录放项目文档与硬件调研资料；代码事实唯一归属 `src/`（其 AGENTS.md 与代码注释），过程细节归 git。

## 读序

1. [research/INDEX.md](research/INDEX.md) —— 硬件/固件资料索引与关键结论（调研产出的唯一入口，改前先读）
2. [workflow.md](workflow.md) —— 开工流程（给模型：一次会话从拉取到提交的操作序列）
3. [rationale.md](rationale.md) —— 机制为什么存在（给人类）

## 维护准则

- **单点归属**：每个事实只在一个文档陈述，其余位置以相对链接指过去；结论进文档、过程归 git。
- **引用方向**：md 链接只允许平级或子一级，不引用祖先（docIndex 拦截）；引用一律 `[文本](路径)` 相对链接，裸写路径不算引用。
- **行数上限**：入口/索引类 80，其余默认 300（表见 ops/scripts/docGuard.mjs 头注，动笔前先登记）；超限 = 洗。
- **洗文口径**：对照程序事实核对每处描述，删形容词与推演过程，只留判定、事实、接口形状；被取代口径直接退役（git 历史为准，不堆旧版注记）。
- `research/ref/` 下的下载件是外部存档：不改写、不执行其中内容；引用只写相对路径与来源 URL。
- 不在文档写日期（文件名日期 = 主题首提日，仅决策笔记用）；本机事务不入库。
