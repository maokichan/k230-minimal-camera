# 决策：外部存档豁免 —— docs/research/ref/ 同 trash/ 一样不进守卫扫描

Status: implemented

## Problem

`docs/research/ref/` 收录外部原始资料（嘉楠 k230_docs 的 md、wiki HTML 存档等）。它们自带上游仓库的内部导航链接（如 `../../00_hardware`），在本仓库解析必然"向上/失效"，触发 docIndex 拦截；且体量 80–120K 行级，必然超 docGuard 上限。而 docs/AGENTS.md 规定存档件**不改写**——为过门禁去改上游文档，性质就变了。

## Decision

三守卫把 `docs/research/ref/` 列为存档豁免目录（与 `trash/` 同待遇）：

- docIndex：ref/ 下的 .md 不作为被扫描文档（其自身出链不校验）；
- repoGuard：ref/ 不在扫描范围；
- docGuard：ref/ 不计行数上限。

豁免只针对 ref/ 自身；主题总结与 INDEX.md **照常受管**，它们指向 ref/ 的跟踪边保留——索引与存档的对应关系仍受漂移提醒保护。

## Alternatives considered

- 洗掉上游文档里的内部链接以过门禁：违背"存档不改写"，且改不动（同类链接在上游文档里会成批出现）。
- ref/ 整目录 gitignore 不入库：调研资料失去随库分发与离线可用性，与建库目的相悖。
- 只豁免 docIndex、docGuard 照拦：同一份存档在一条链上待遇不一致，守卫语义碎裂。

## Consequences

- 存档件自身的绝对路径/链接形态不再被守卫看见（repoGuard 对 HTML 本来就不扫，md 豁免后覆盖面一致）。
- 新增外部存档到 ref/ 无门禁阻力；放错位置（ref/ 之外）的项目自撰文档照常受管。
